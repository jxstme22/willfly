# Optional scanner and LP Agent integration

The current capability matrix intentionally reports LP Agent, RHTrenches and
Mezzanine as unavailable for a verified Robinhood production read API. Native
RPC capture remains independent. Browser observations and advertised features
must not be presented as an API integration or a service guarantee.

When access is verified, add endpoint, authentication, paging, freshness,
field semantics, terms, native ETH/WETH handling and raw evidence before
enabling the adapter. Missing sources have an explicit fallback.
