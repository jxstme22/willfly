# LP eligibility review

Compare fixed-wide, volatility-range, spot and idle policies under the same
capital, timing, price, fee, gas, range and drawdown rules. Nominal APR is not a
selection criterion. LP mode changes must preserve the shared portfolio and
must not double-allocate cash already committed to spot. Stress outputs remain
modeled when exit depth or hook/token support is missing.

Current decision: `DISABLED_PENDING_EVIDENCE`.

The structured LP evidence gate is not satisfied: no independently verified
Robinhood deployment/bytecode, token ordering, hook behavior, complete receipt
set, gas denomination and observed position checkpoint sample is recorded.
