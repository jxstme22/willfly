# Baseline laboratory v0.2 review template

The baseline machinery is implemented, but this review is not a profitability
claim. Populate it only after a locked walk-forward run has enough independent
chronological blocks and the replay data-quality gates are satisfied.

Required report fields are net/excess return, drawdown, failure rate, turnover,
exposure, calibration, cost/delay stresses, capital scenarios, excluded and
censored episodes, and paired uncertainty. The strongest practical baseline
must be selected before any neural holdout comparison.

Current status: `INCONCLUSIVE` pending verified launch history, the 72-hour
recorder gate, adequate observed episodes and historical execution state.
