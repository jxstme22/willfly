# Willfly v0.6 research package — gated

> Historical plan/report. The 13 September Astra audit found incomplete integration and correctness gaps. Use the current [audit](../reports/astra-deep-audit.md) and the version 2.0 next roadmap before implementation or readiness decisions.

This release records the reproducible Phase 8 shadow protocol and its current
go/no-go state. The package contains the frozen-config procedure, restart-safe
hypothetical decision store, degraded-mode rules and time/coverage audit.

Decision: **continue shadow / do not fund**. The required observation window
has not yet been collected, Pons lifecycle and provider-independence gates are
still open, and LP remains disabled pending verified pool-family evidence.
No positive shadow result may be represented as funded performance. A future
review must attach the config hash, source/config hashes, decision ledger,
availability audit, replay reconciliation, cost stresses and uncertainty
report before considering a separately authorized pilot.
